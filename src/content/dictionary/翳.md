# 典故單字考據：翳

## 1. 基本字音與字義

- 審定注音：ㄧˋ（yì）
- 部首筆畫：羽部 / 總筆畫 17 畫
- 白話本義：
  - 名：用羽毛製成的車蓋。
  - 名：供作蔽覆的東西。
  - 名：一種瞳孔為白膜所蒙蔽，以致無法看清東西的眼疾。
  - 動：隱藏、隱居。
  - 動：遮蔽。
  - 動：摒棄。

## 2. 古籍出處與經典引文

- 經史子集出處：
  - 《說文解字》〈羽部〉：「翳，華蓋也。」
  - 《晉書》〈卷二五．輿服志〉：「戎車，駕四馬，天子親戎所乘者也。載金鼓、羽旗、幢翳。」
  - 《管子》〈小匡〉：「九合諸侯，一匡天下，甲不解壘，兵不解翳。」
  - 《文選》〈左思．詠史詩八首之七〉：「陳平無產業，歸來翳負郭。」
  - 《三國志》〈卷一一．魏書．管寧傳〉：「寧抱道懷貞，潛翳海隅。」
  - 《楚辭》〈劉向．九歎．遠逝〉：「阜隘狹而幽險兮，石嵾嵯以翳日。」
  - 《國語》〈周語下〉：「而又奪之資，以益其災，是去其藏而翳其人也。」
  - 《新唐書》〈卷一五六．李元諒傳〉：「元諒培高浚淵，身執苦與士卒均，菑翳榛莽，闢美田數十里。」

- 歷代詩詞賦名篇：
  - 唐代．曹松〈碧角簟〉詩：「八尺碧天無點翳，一方青玉絕纖塵。」
  - 宋代．蘇軾〈贈眼醫王生彥若〉詩：「運鍼如運斤，去翳如拆屋。」
  - 唐代．劉禹錫〈磨鏡篇〉：「流塵翳明鏡，歲久看如漆。」
