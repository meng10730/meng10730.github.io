每次走進書店，我總習慣先看看書名。對我來說，能吸引我的書名最直觀且最好理解的就好。而《頭腦好的人說話前思考的事》剛好戳中我心裡的理想狀態——我也想變成一個說話之前會先思考、懂得察言觀色、甚至能讓人覺得「這個人無時無刻都在給對方情緒價值」的人。\
\
透過閱讀這本書來提升自己，在談話方面變得更有自信、變得更有邏輯。當一個人的說話能力提升了，不只是能讓對方聽得懂，更會讓我越來越喜歡表達自己的看法。\
\
在能接受書名後，我會試著翻到背面，檢視作者想闡述的觀念對我來說是否有主觀上的幫助，以此書為例:「當一般人只在乎說話內容，聰明人卻會知道何時該保持沉默、何處該替人著想。」不是說我真的很衝動性消費，但光看到這一句，我的錢包就緩緩掏出來了。\
\
好啦，那有人問，網路上資源這麼多，為何不直接看影片作筆記就好呢?問就是習慣問題，相較於寫在 goodnote 上，我還比較喜歡在書上直接畫重點做筆記，寫字的感覺令人愉悅(怪人…..)。\
\
\
\
想提一下書中部分思考法則，稍微說明一下作者與自己的看法。法則四「聰明的人不會駁倒對方」，簡單來說就是「對事不對人」，誠然，大家都會講，但實際上是對人還是對事其實很明顯。例如在報告或小組討論時，有時候會遇到組員(先說，不是文學課的組員)不是很專心。以前可能會忍不住想對人發火，如：「NMD 躺分仔，裝逼我讓你飛起來!」(?)之類的話，這樣其實就已經在針對人了。\
\
但現在我試著轉個彎，如果我們針對問題。我會問他：「欸，你是不是今天有什麼事比較忙？還是分手了？」這樣一來，不但能讓對方感受到尊重，也能更直接地把注意力放在「我們該怎麼處理這件事」上。也許對方真的有難處，也許只是暫時走神，但我不急著貼標籤，而是先搞清楚狀況，然後說：「那我們可不可以約下一次討論，先各自處理好自己的狀態，再來好好完成這件事？」這樣大家或許比較能心平氣和地面對問題。\
\
接著，我想再舉書中的法則三「不要假裝聰明，而是要聰明行事」，有時當對方尋求一個解答或是方法的時候，或許有人為了顯得思考很快、反應很快，在幾乎未思考的情況下，便提出回答。這時候勢必會出現一個小問題:他確實有講，只是好像什麼都沒有說。簡單來說，仔細想想，還真的沒什麼內容。\
\
舉個作者的例子: 作者當時的上司在開會時說：「我們要掌握使用者的需求，採取合適的策略。」這樣聽起來像是有在思考，可是到底怎麼掌握需求？要用什麼方法？卻一句也沒說出來。如果當時我在現場，我可能會進一步思考：那我們要不要先進行市場調查？或是收集一些民眾的意見？我們可以看看現在市面上那些受歡迎的產品，有哪些功能或設計是使用者喜歡的，然後再分類整理出哪些元素可以被我們的產品吸收或改良。這樣子一步一步找出真正有用的細節，再加進來，產品才有可能變得更好。\
\
有些扯遠了，再拉回來主題。對作者來說聰明行事的定義是這樣的:「為對方著想，進而使其產生信任、建立長久的合作關係」，我只能說，這句話特別通用，無論是用在交友方面，商業洽談方面，又或者是同部門的相處方面上，都可以適用，如同作者在初入職場時，不小心面臨客戶流失的問題，在作者持續的與上司、客戶雙向溝通後，所幸客戶最後仍然續約，而上司對作者處理事件的結果很滿意，覺得他確實有在為公司著想，便又繼續聘任作者。\
\
這種觀念或許可以用在日常生活上，可能的情境如:你跟一位朋友去吃飯，正在選擇前往哪間餐廳，你的朋友說:「我都可以。」這是大多數人(我認識的)最常用的回答，感覺確實回答問題了，但如果真的隨便吃，又可能對餐點嫌東嫌西的(這樣就沒有為對方著想)。你的眉頭一皺，正在思考對方可能會想吃什麼。便利商店?小火鍋?還是精緻餐點?如果能試著問問看對方就顯得更完美了(這樣或許就能選到雙方都滿意的餐廳了)。\
\
法則二的部分，其實是在說「你聰不聰明，並不是你說了算，而是別人感覺出來的」。怎麼說呢？有時候我們會覺得：「我讀了好多書、看了很多報告，寫過一堆細項分析，接過不少案子，也去過不少工作坊、講座，還追蹤一堆論壇，甚至每期科普雜誌都不錯過」，然後心裡就會默默想：「我應該算是個挺聰明的人吧？」\
\
可是——那只是「你自己覺得」而已。作者在這一則法則裡特別強調的，是「別人怎麼看你」才是真正的關鍵。別人會覺得你聰明，並不是因為你知道了多少東西，而是你說話的時候能不能把一件事講得有邏輯、有脈絡、有前因後果，讓人聽得懂你在說什麼。真正的智慧，是「你說得出來，還能讓別人聽得懂」；而你自己心裡知道的那些，只能算是「知識」，還稱不上智慧。\
\
而且啊，每個人的三觀都不太一樣。如果跟一個跟你價值觀接近的人講話，說不定根本不用講太多，他就能秒懂你在說什麼。但如果遇到跟你價值觀完全不同的人，你再怎麼講「我覺得這樣就可以了」，對方還是可能聽不懂，甚至會覺得「我找你來是要解決問題，但怎麼越改越有問題?」。\
\
你如果又塞了一堆專有名詞，硬是要展現自己的厲害，對方只會更加聽不懂，然後在心裡默默 OS：「你到底是在公三小？」所以啊，作者提到的「為對方著想」，就是指：你在講話的時候，要假設「對方什麼都不知道」。用這種態度去講話，你才會願意慢慢說明，把你的價值觀、你的想法用對方能懂的方式表達出來。

當你能顧及對方的理解能力，對方就比較有可能站在他的角度，理解你說的話。這樣彼此就能好好討論，不只更容易碰撞出新的想法，聊天的品質也會跟著提升。\
\
那有人問，有沒有那種「自己明明講了很多，但對方就是聽不懂」的經驗？有啊，我自己打工的時候就遇過。那時候我在補習班工作，負責輔導學弟的課業。因為我是念電機科的嘛，所以我教的內容多半是一些基本電學、電子學的東西，像是歐姆定律之類的。\
\
學弟已經高二了，但他很多高一就該學會的東西還是不太懂。當下我真的有點震驚，心裡想：「這不是早該會的東西嗎？怎麼到高二還沒記起來公式長什麼樣子？」那一瞬間我是真的有點矇。\
\
我自己高三在讀完電子學之後，對電路圖的判斷已經算是熟練的了，看到圖大概知道怎麼畫、怎麼算，稍微運算一下就能得到答案。可是，當我把這些方法一步步教給學弟的時候，他好像「有聽沒有懂」，聽是聽到了，可是到真的要動筆寫的時候，他整個就卡住了，像是突然當機一樣。\
\
那時候我講了將近半個小時，從頭到尾仔細地講，但他還是完全抓不到重點。我心裡不禁納悶：「到底是哪裡出了問題？為什麼我講這麼多，對方還是無法理解？」這真的是個小困擾，也讓我開始反思是不是我的講解方式不夠適合他的程度。\
\
後來詢問老師，老師建議盡量一步一步慢慢來。如果發現他好像吸收得沒那麼快，那我就會再把每一個步驟切得更細、更清楚一點，然後再把那些步驟一一講給他聽。每講完一個步驟，檢查他有沒有真的懂，是不是真的會了。雖然整體的速度可能會變得比較慢一點，但如果能這樣紮實地教會他，那等他真的學起來之後，進步的速度其實是會變很快的。\
\
有時候我也會在想，是不是我一開始講得太快、太理所當然，才讓他一臉茫然。畢竟我自己已經懂的東西，對他來說可能還是全新的，甚至連基礎的地方都還卡住。我以前也有那種「為什麼你連這都不會」的念頭冒出來，可是後來我發現，與其責怪他不懂，不如換個方式、換個角度讓他比較容易理解。\
這樣一來，他學得比較輕鬆，我教得也比較有成就感。然後看著他從不懂到會、從慢慢來到能自己解題，那個過程真的會覺得很值得。雖然一開始可能得花很多時間，但只要前期的基礎打穩，進步勢必是指數上升的。\
\
閱讀本書後，我試著把書裡的一些觀念變成自己的想法，最後得出一個結論【與其一直問「為什麼」，不如改問「怎麼辦」】。因為不停地問「你為什麼要這樣做」，其實只是想挑毛病、找錯誤，但這樣做根本無法真正解決眼前的問題。反過來說，如果能改成問「那我們現在該怎麼辦呢？」這才是真正邁向解決問題的第一步。\
\
這讓我在每一次想要開始亂轟亂炸之前，試著先退一步，用比較理性的角度來看整件事，慢慢分析問題的本質，接著再找出適合的方法，逐步去解決它。在這個過程中，記得要先確認自己的目的是什麼，保持一點好奇心，去了解事情背後的來龍去脈。\
\
同時，也要分辨清楚現在是在跟誰談話、討論的是什麼議題，還有對方真正想聽的是什麼。不要急著下判斷，也不一定要馬上提出自己的意見，這時候只需要提供一個思考的方向，讓對方有空間可以一起思考、一起前進。\
\
讀完《頭腦好的人說話前思考的事》，我試著實行作者提出的觀點。開始願意慢一點再說話，開始會想一下對方的立場、用字、感受，然後再決定要怎麼說、說多少。\
\
這本書像是一面鏡子，讓我看見自己以往在溝通上的盲點，。學會把焦點從「我怎麼想」轉移到「對方能不能懂」，從「我要說什麼」變成「我該怎麼說」，不再急著表現自己，而是更在意我們能不能好好交流。\
\
也許變得「頭腦好」不是一瞬間的開竅，而是一點一滴的練習與體會。而我想這本書，使我重新審視幾個學習階段以來，在溝通上的盲點，並從中改進說話的方式，以增進口才，並保持持續學習的初衷。
